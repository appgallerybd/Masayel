# মাসআলা শেয়ারিং

ইসলামিক মাসআলা (ফিকহ) শেয়ারিং ও Q&A প্ল্যাটফর্ম। Next.js (App Router) + Firebase।

## রোডম্যাপ — সব ধাপ সম্পন্ন ✅

1. ✅ প্রজেক্ট সেটআপ (Next.js, Tailwind, Firebase কনফিগ)
2. ✅ UI ফাউন্ডেশন (বাটন, কার্ড, ব্যাজ, ইনপুট, জ্যামিতিক মোটিফ)
3. ✅ হোমপেজ + হেডার/ফুটার/বটম-ন্যাভ
4. ✅ ক্যাটাগরি পেজ
5. ✅ মাসআলা ডিটেইল পেজ (কুরআন/হাদিস রেফারেন্সসহ)
6. ✅ সার্চ
7. ✅ স্কলার প্রোফাইল পেজ
8. ✅ প্রশ্ন সাবমিশন ফর্ম + বুকমার্ক
9. ✅ অ্যাডমিন প্যানেল
   - ৯ক. লগইন (Firebase Auth)
   - ৯খ. সাইডবার + ড্যাশবোর্ড
   - ৯গ. মাসআলা ম্যানেজমেন্ট (তালিকা/নতুন/এডিট/ডিলিট)
   - ৯ঘ. ইউজার/রোল ম্যানেজমেন্ট (RoleGuard সহ, superadmin-only)

## চালু করার ধাপ

```bash
npm install
cp .env.local.example .env.local
# .env.local এ Firebase কনসোল থেকে কী বসাও
npm run dev
```

তারপর ব্রাউজারে খোলো: http://localhost:3000 (পাবলিক সাইট) এবং http://localhost:3000/admin/login (অ্যাডমিন)

## এখন যা এখনো "নমুনা/ডেমো" পর্যায়ে আছে — Firestore ওয়্যারিং বাকি

কোডে সব জায়গায় `TODO` কমেন্ট দিয়ে চিহ্নিত করা আছে। মূলত:

- **`lib/mock-data.ts`** — ক্যাটাগরি, মাসআলা, স্কলারের নমুনা ডেটা। Firestore যুক্ত হলে এখান থেকে সরিয়ে Firestore কুয়েরি ব্যবহার হবে।
- **`lib/admin-store.ts`** / **`lib/admin-users-store.ts`** — অ্যাডমিন প্যানেলের অ্যাড/এডিট/ডিলিট এখন `localStorage`-এ হচ্ছে (ডেমো হিসেবে কাজ করে, রিফ্রেশেও থাকে)। Firestore যুক্ত হলে এই দুই ফাইলের ফাংশনগুলো `addDoc`/`updateDoc`/`deleteDoc`/`onSnapshot` দিয়ে প্রতিস্থাপিত হবে — বাকি UI কোড অপরিবর্তিত থাকবে।
- **`middleware.ts`** ও লগইন পেজের সেশন কুকি — এখন Firebase ID টোকেন সরাসরি ক্লায়েন্ট-সাইড কুকিতে বসানো হচ্ছে, যেটা নিরাপদ না। উৎপাদনে যাওয়ার আগে একটা `/api/session` রুট বানিয়ে `firebase-admin`-এর `createSessionCookie` দিয়ে httpOnly কুকি বসাতে হবে, আর `middleware.ts`-এ `verifySessionCookie` দিয়ে যাচাই করতে হবে।
- **সার্চ** — এখন মক ডেটার উপর ক্লায়েন্ট-সাইড ফিল্টার। Firestore-এ নেটিভ ফুল-টেক্সট সার্চ নেই, তাই ভালো সার্চের জন্য Algolia বা Typesense-এর মতো সার্ভিস লাগবে।
- **`MasalaEditor`** এর বিবরণ ফিল্ড এখন প্লেইন টেক্সটএরিয়া — চাইলে পরে একটা রিচ-টেক্সট এডিটর (যেমন Tiptap) দিয়ে প্রতিস্থাপন করা যায়।
